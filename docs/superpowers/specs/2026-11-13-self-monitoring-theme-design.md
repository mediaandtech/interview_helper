# 테마 전환: 답변 복기 → 화상 인터뷰 셀프 모니터링

작성일: 2026-11-13 · 상태: 사용자 검토 대기
표기: **[사용자 결정]** 대화에서 정한 것 / **[설계자 판단]** 제안한 것(바꿔도 됨)

## 의도

이 도구의 핵심은 질문에 대한 답변을 돌아보는 것이 아니라, **화상 인터뷰 화면에 비친 나의 모습(목소리의 일정함·높낮이·시선 처리 등)을 모니터링하며 스스로 분석하는 것**이다. [사용자 결정]
점수·등급·자동 평가 없이 사용자가 판단한다는 기존 방침은 유지한다. '분석'은 도구가 해석을 내리는 것이 아니라 스스로 분석할 재료를 보여 주는 것이다. [설계자 판단]

## 목표 / 비목표 / 실패 조건

- 목표: 첫 화면부터 "내 화면 속 모습을 모니터링하고 분석하는 도구"로 읽힌다. 말하는 도중 측정값이 기본으로 보이고, 끝난 뒤 시간 흐름으로 스스로 짚어 본다.
- 비목표: 새 센서·새 분석 알고리즘, 점수·판정·조언 문구 추가, 저장 방식 변경.
- 실패 조건: 문구는 바뀌었는데 기본 흐름이 여전히 "질문 입력 → 측정값 숨김 → 복기"로 느껴지는 것. 판정처럼 읽히는 문구가 새로 생기는 것.

## 접근 방식

1. 실시간 중심: 측정값 상시 표시, 사후 화면은 보조. — 말하면서 수치를 보느라 집중이 흐트러질 수 있다.
2. **실시간 + 사후 분석 동등** — 측정값을 기본 표시하고, 끝나면 시간 흐름 그래프로 분석. 기존 리포트 화면을 그대로 살린다. **[사용자 결정: 채택]**
3. 흐름 유지, 문구만 변경 — 모니터링 느낌이 살지 않는다.

## 변경 내용

### 동작
- `측정값 숨기기` 기본값을 **꺼짐**으로 바꾼다(`js/ui/setup.js` focus-mode 체크박스와 `app.settings?.focusMode ?? true` 기본값). 숨기기 옵션 자체는 남긴다. [사용자 결정의 구현]
- 질문 입력은 없애지 않고 **선택 항목인 '연습 이름표'**로 바꾼다. 같은 이름표끼리 비교하는 기존 동작(`report.js` 문자열 일치)은 그대로 둔다. 내부 키 `settings.question`, DOM id는 바꾸지 않는다. [설계자 판단]
- 관찰 요약에 **'음량 변화 폭'(발화 중 dB 표준편차)** 1개를 추가해 "목소리의 일정함"을 수치로 볼 수 있게 한다. 지금은 평균 음량만 있다. 판정 없이 숫자만 보여 준다. [설계자 판단 — 원치 않으면 제외]

### 화면 문구 [설계자 판단, 세부 표현은 구현 시 조정 가능]
| 위치 | 현재 | 변경 |
|---|---|---|
| `index.html` title | 면접 답변 복기 도구 | 화상 인터뷰 셀프 모니터 |
| 상단 바 brand (`components.js`) | 답변 복기 | 셀프 모니터 |

| 설정 카드 (`setup.js`) | 연습할 질문 / "답변을 기록하고 직접 돌아봐요" | 연습 이름표(선택) / "화면 속 내 목소리와 시선을 보면서 스스로 분석해요" |
| 숨기기 스위치 | 답변 중에는 측정값 숨기기 / 복기 때 확인해요 | 말하는 동안 측정값 숨기기 / 끝난 뒤 분석 화면에서 확인해요 |
| 시작·종료 버튼 | 답변 시작 / 답변 끝내기 | 모니터링 시작 / 모니터링 끝내기 |

| 비교 카드 | 같은 질문의 이전 답변과 비교 | 같은 이름표의 이전 기록과 비교 |
| 메모 탭 | 전체 복기 | 전체 메모 |
| 기타 | "답변" → 상황에 따라 "기록"/"세션" (`practice.js`, `media-recorder.js`, `gazetest.js`, `report.js`) | |
