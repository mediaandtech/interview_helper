# 답변 화면 — MASTER 보충 규칙

- 상단 바 오른쪽: 녹화 배지(녹화 시에만, destructive) · `측정값 보기/숨기기`(outline) · (데모) `실제 카메라로 전환`(ghost) · `답변 끝내기 (Esc)`(destructive).
- 질문 줄: 질문 배지 + 질문(한 줄 말줄임) + 녹화 상태 문구 + 오른쪽 타이머(`--fs-clock`, 설정 시간 이후는 `+MM:SS`와 '설정 시간 이후', 색 변화 없음). 아래 4px 진행 막대.
- **집중 모드(기본)**: 웹캠만 전체 폭, 아래 안내 한 줄. 웹캠 위 표시(시선 알약·각도)도 숨김.
- **측정값 보기**: 웹캠 | 340px 열(속도·크기·음높이 지표 카드 + 고개·눈 배지). 지표 카드 문구 `--fs-metric`, 숫자는 오른쪽 위 보조.
- 웹캠 위: 가운데 시선 알약(반투명 바탕), 왼쪽 위 고개 각도, 오른쪽 위 데모 배지.
