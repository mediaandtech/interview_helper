# 연습 화면 — MASTER 보충 규칙

이 문서의 규칙이 MASTER보다 우선합니다.

## 배치 (1280×720 기준)
- 상단 바 44px → 카메라 바로 아래 가운데 **시선 알약**(가장 먼저 눈에 들어가는 요소)
- 왼쪽 60%: 웹캠(영상 전체가 보이게 contain, 테두리 3px = 시선 상태)
- 오른쪽 40%: 위에서 아래로 **속도 → 크기 → 억양 → 남은 시간** (시간 칸은 다른 칸의 0.85배 높이)
- 오른쪽 위: 종료(빨강 테두리). 데모 중이면 왼쪽에 `실제 카메라로 전환`

## 상태 단어
| 패널 | 단어 | 색 |
|---|---|---|
| 속도 | 느림 / 적정 / 빠름 / 측정 대기 | 적정 초록, 범위 밖 30 이내 주황, 그 밖 빨강 |
| 크기 | 작음 / 적정 / 큼 / 쉬는 중 / 측정 대기 | −6~+8 dB 초록, −10~−6·+8~+12 주황, 그 밖 빨강 |
| 억양 | 단조 / 적정 / 풍부 / 측정 대기 | 단조 주황 |
| 시간 | `MM:SS` / `+MM:SS` | 1분 남으면 주황, 초과 빨강(자동 종료 없음) |
| 시선 | 정면 / ○○을 보고 있어요 / 얼굴이 보이지 않아요 / 시선 측정 대기 | 1.5초 주황, 3초 빨강, 복귀 0.5초 |

- 상태 단어는 색과 **같은 안정된 상태**를 따른다(초록 패널에 '빠름'이 보이면 안 됨).
- 화면 갱신은 10Hz, 값이 바뀐 요소만 다시 그린다. p5 캔버스는 웹캠·억양 2개만.

## 웹캠 오버레이 우선순위
1. 테두리 색(시선 상태) 2. 고개 화살표 3. 눈 화살표 4. 얼굴 점(옅게) 5. 각도 숫자(왼쪽 위, 작게)
디버그(`?debug=1`)에서만 3×3 시선 그리드와 원시 값 표시.
