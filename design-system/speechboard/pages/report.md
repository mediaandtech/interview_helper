# 리포트 화면 — MASTER 보충 규칙

실시간 화면이 "지금 상태"라면 리포트는 "시간에 따른 변화"입니다. 그래프 중심.

## 순서
1. 점수(64px) + 한 줄 결론(가장 잘한 점 1개 + 가장 아쉬운 점 1개) + 메타(유형·목표/실제 시간·날짜)
2. 요약 5칸: 정면 응시 / 평균 속도 / 크기 이탈 / 억양 / 시간 — 색은 **목표 대비 의미**로(예: 정면 77% < 목표 80% → 주황)
3. 시간 흐름 그래프 4줄(시선 띠·속도·크기·억양), **모든 줄이 같은 시간축**, 적정 범위는 옅은 초록 띠
4. 이탈 구간 표(시작·내용·지속) | 다음 연습에서 고칠 것 3개 — 나란히
5. 지난 기록 비교(있을 때) → 버튼: 다시 연습 / 설정으로 / PDF로 저장

## 규칙
- 실시간 화면과 같은 상태색·단어를 쓴다.
- 그래프 위 마우스: 세로선 + 그 시각의 값, 이탈 구간이면 해당 조언 문장.
- 시간 표기: 타임스탬프 `M:SS`, 초과/부족 `+MM:SS`.
- 인쇄(PDF): 흰 배경·검정 글자, 버튼 숨김, 그래프는 이미지로 바꿔 한 페이지에.
