# 복기 화면 — MASTER 보충 규칙

- 상단 바 오른쪽: `이전 답변과 비교`(outline, 비교 카드로 이동) · `같은 질문 다시 답변`(primary).
- 질문 줄 + 메타(날짜·설정/답변 시간·“자동 점수·평가 없음”).
- 2열(1.55 : 1): 왼쪽 영상 카드(녹화 없으면 빈 상태, footer 다운로드·삭제) + 시간 흐름 카드(p5 4줄 그래프, 슬라이더, 현재 위치 설명) / 오른쪽 관찰 요약(2열 숫자) · 메모(탭: 현재 위치 / 전체 복기) · 참고 범위와 다른 구간(표, 시작 시각 누르면 이동).
- 아래: 이전 답변 비교 카드, 보관 안내, `질문·설정 변경` · `인쇄/PDF` · `보관한 답변·메모 모두 삭제`(destructive).
- 그래프 색: 정면 띠 진한 파랑(범위 안)·회색(밖)·어두운색(검출 없음), 선은 `--chart-*`, 참고 범위 음영은 회색.
- 인쇄: 흰 배경, 버튼·입력 숨김, 숨겨진 탭 패널도 출력, 그래프는 이미지로.
