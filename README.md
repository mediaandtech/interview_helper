# SpeechBoard: 발표 연습 대시보드

웹캠과 마이크만으로 **시선(정면 응시), 말하기 속도, 목소리 크기, 음성 높낮이, 발표 시간**을 실시간으로 보여 주고, 끝나면 피드백 리포트를 만들어 주는 발표 연습 도구입니다.
서버 없이 브라우저(Chrome)에서만 동작합니다.

- 설계 문서: `docs/superpowers/specs/2026-11-13-presentation-coach-design.md`
- 구현 계획: `docs/superpowers/plans/2026-11-13-presentation-coach.md`

## 실행 방법

1. 터미널에서 프로젝트 폴더로 이동한 뒤 실행합니다.
   ```bash
   npm start            # = python3 scripts/serve.py
   # 포트를 바꾸려면: python3 scripts/serve.py 9000
   ```
2. 터미널에 표시된 주소(`http://localhost:포트`)를 **Chrome**에서 엽니다.
3. 카메라·마이크 권한을 **허용**합니다.

> `index.html`을 더블클릭해서 열면(`file://`) 카메라와 얼굴 인식 모델이 동작하지 않습니다. 반드시 위 방법으로 여세요.
> `scripts/serve.py`는 캐시를 끈 서버라서, 코드를 고친 뒤 새로고침만 하면 바로 반영됩니다.

### 데모 모드 (카메라·마이크 없이)

설정 화면의 **"데모 데이터로 체험하기"** 버튼을 누르거나 주소 뒤에 `?demo=1`을 붙이면, 가상 데이터로 연습 화면이 바로 시작됩니다.
약 1분 주기로 정상 → 원고 보기(고개 숙임) → 목소리 작아짐 → 말이 빨라짐 → 눈만 옆으로 → 억양 단조 → 잠시 쉼 → 고개 돌림 → 목소리 커짐 → 말이 느려짐 순서가 반복되며, 화면 오른쪽 위 `DEMO` 표시 옆에 지금 장면이 나옵니다. 시나리오는 `js/sensors/demo.js`의 `DEMO_SCENES`에서 바꿀 수 있습니다.
시연장에서 카메라가 말을 듣지 않을 때 예비로도 쓸 수 있습니다.

### 시선 인식 테스트

설정 화면의 **"시선 인식 테스트"** 버튼(또는 주소 뒤 `?gazetest=1`)으로 엽니다. 약 50초 동안
정면 기준 잡기 → 정면 → 고개 왼쪽/오른쪽/숙이기/들기 → 눈만 아래/왼쪽/오른쪽 → 다시 정면 을 차례로 안내하고,
단계마다 3초씩 측정해 **기대한 방향과 실제 감지가 몇 % 맞았는지** 표로 보여 줍니다(60% 이상이면 통과).
- 진행 중에는 고개 각도와 눈 방향 값이 막대로 보이고, 초록 영역이 "정면"으로 보는 범위입니다.
- 결과 아래 **진단**이 고칠 값을 알려 줍니다(예: 위아래가 반대 → `GAZE.flipPitch: true`, 눈 신호가 기준에 못 미침 → `GAZE.eyeThreshold` 낮추기).
- **결과 복사**를 누르면 텍스트로 복사됩니다. 그대로 붙여 넣어 공유하면 됩니다.

### 디버그 모드

주소 뒤에 `?debug=1` 을 붙여 열면 3×3 시선 그리드와 함께 화면 왼쪽 아래에 원시 값(dB, 음높이, 속도 보정계수, 시선 방향 등)이 표시됩니다. 기준값을 조정할 때 사용하세요.

### 테스트

```bash
npm test   # Node 20 이상, 설치할 패키지 없음
```

## 사용 흐름

1. **설정**: 발표 유형을 고르고, 발표 시간을 정한 뒤, "준비 확인 시작"을 누릅니다.
   - 2초 동안 카메라를 정면으로 봅니다. 이 자세가 "정면" 기준이 됩니다.
   - 4초 동안 안내 문장을 평소 목소리로 읽습니다. 이 목소리가 크기·높이의 기준이 됩니다.
2. **연습**: 3초 카운트다운 후 시작합니다. `Esc`, `Space`, [종료] 버튼 중 하나로 끝냅니다.
3. **리포트**: 점수, 지표 요약, 시간 흐름 그래프(마우스를 올리면 설명), 고칠 점 3가지를 보여 줍니다. "PDF로 저장"은 브라우저 인쇄 창에서 "PDF로 저장"을 고르면 됩니다.

## 화면 읽는 법 (연습 화면)

- **위쪽 가운데(카메라 바로 아래)**: 시선 상태 알약. 왼쪽은 *지금* 상태(정면 / ○○을 보고 있어요), 오른쪽 `누적 84%`는 시작부터 지금까지 정면을 본 비율. 그 아래 `고개 · 눈`이 따로 표시되어 고개를 돌린 건지 눈만 돌린 건지 구분됩니다.
- **웹캠**: 고개가 벗어나면 코에서 굵은 화살표, 눈만 벗어나면 두 눈에서 파란 가는 화살표. 정면이면 코에 작은 초록 원. 테두리 색 = 시선 상태. 왼쪽 위 작은 글씨는 고개 각도(보조 정보).
- **오른쪽 패널**: 큰 글자가 상태(느림/적정/빠름, 작음/적정/큼, 단조/적정/풍부), 게이지의 초록 띠가 적정 범위, 마커가 지금 위치, 숫자는 오른쪽 위에 작게.
- **남은 시간**: 큰 숫자 + 진행 막대. 1분 남으면 주황, 넘기면 빨강 `+00:24`(자동 종료 없음).
- 데이터가 없으면 숫자 대신 `측정 대기`, 말하지 않는 동안 크기는 `쉬는 중`(작음으로 치지 않음).

## 디자인 토큰 (`js/config.js`)

색은 `THEME`(배경 `#111820`, 패널 `#1d2935` 등), `STATUS_COLORS`(적정 `#73bf69` / 주의 `#ff9830` / 이탈 `#f2495c` / 대기), `SERIES_COLORS`(그래프 선)에서만 관리합니다. 시작할 때 CSS 변수로 들어가고 p5 그림도 같은 값을 씁니다.

## 기준값 조정 (`js/config.js`)

코드를 몰라도 이 파일의 숫자만 바꾸면 됩니다. 저장하고 새로고침하면 바로 적용됩니다.

| 바꾸고 싶은 것 | 값 | 기본 |
|---|---|---|
| 유형별 적정 속도, 정면 응시 목표 | `PRESETS` | 수업 270~330 / 면접 260~320 / 피칭 290~350, 80~85% |
| 고개를 얼마나 돌려야 "정면 아님"인지 | `GAZE.yawDeg`, `GAZE.pitchDeg` | 15°, 12° |
| 눈만 돌렸을 때 민감도 (클수록 둔감) | `GAZE.eyeThreshold` | 0.5 |
| 몇 초 이탈하면 주황/빨강 | `GAZE.warnSec`, `GAZE.badSec` | 1.5초, 3초 |
| 잠깐 패널 보는 것 봐주기 | `GAZE.forgiveSec` | 1.5초 |
| 목소리 크기 적정/주의 범위 (기준 대비 dB) | `AUDIO.okRangeDb`, `AUDIO.warnRangeDb` | -6~+8, -10~+12 |
| 조용하면 "말 안 함"으로 볼 기준 | `AUDIO.silenceBelowBaseDb` | 기준보다 18 dB 작으면 |
| "단조" 판정 기준 (반음) | `PITCH.monotoneSt` | 1.5 |
| 패널 색이 바뀌기까지 유지 시간 | `UI.hysteresisSec` | 1초 |
| 점수 비중 | `SCORE.weights` | 시선 35 / 속도 20 / 크기 20 / 시간 15 / 높낮이 10 |

**조정 팁**
- 시선이 너무 자주 빨개지면 `GAZE.yawDeg`·`GAZE.eyeThreshold`를 조금 올립니다.
- 말하는데도 "—"가 나오면 `AUDIO.silenceBelowBaseDb`를 올립니다(22 정도).
- 속도가 실제보다 낮거나 높게 나오면 `?debug=1`의 `corr`(보정계수)를 확인합니다. 인터넷이 연결돼 있으면 음성 인식이 자동으로 보정합니다.

## 배포 (GitHub Pages, 선택)

정적 파일뿐이라 저장소를 GitHub에 올린 뒤 Settings → Pages에서 `main` 브랜치 루트를 선택하면 HTTPS 주소로 바로 열 수 있습니다. `vendor/` 폴더(모델 파일 포함)도 함께 올려야 합니다.

## 시연 체크리스트

**전날**
- [ ] 시연용 Mac에서 강의실 프로젝터에 연결해 리허설합니다. 미러링 해상도에서 숫자가 잘 보이는지(1280×720 이상 권장) 확인합니다.
- [ ] Chrome에서 이 주소의 카메라·마이크 권한을 "항상 허용"으로 설정합니다.
- [ ] 카메라가 안 잡힐 때를 대비해 데모 모드(`?demo=1`)로 한 번 돌려 봅니다.
- [ ] 시연용 노트북에서 **시선 인식 테스트**를 돌려 9단계가 모두 통과하는지 확인합니다. 진단에 나온 대로 `js/config.js` 값을 고칩니다.
- [ ] 와이파이를 끈 상태에서도 시선·크기·높낮이·시간이 동작하는지 확인합니다(속도는 추정값으로 동작).
- [ ] 실제 발표 1~2회로 `js/config.js` 기준값을 맞춥니다.

**시연 직전**
- [ ] `npm start`로 서버를 켜고 Chrome 탭을 미리 열어 둡니다.
- [ ] 다른 앱(Zoom 등)이 카메라를 쓰고 있지 않은지 확인합니다.
- [ ] 조명: 얼굴 앞쪽이 밝게, 뒤에 창문이 없게 앉습니다.
- [ ] 보정(준비 확인)은 시연하는 자리에서 다시 합니다.
- [ ] 불안정한 기능이 있으면 숨기지 말고 config로 기준을 완화합니다.

## 폴더 구조

```
index.html, css/style.css       화면과 그라파나 스타일 테마
js/config.js                    모든 기준값
js/util/, js/analysis/          계산 로직 (테스트됨, 브라우저 API 사용 안 함)
js/recorder.js                  10Hz 샘플 기록
js/sensors/                     마이크·음성 인식·카메라(MediaPipe), demo.js(가상 센서)
js/ui/                          설정 / 연습 / 리포트 화면, p5 스케치, components.js(게이지·진행 막대)
vendor/                         p5.js, MediaPipe(오프라인 동작용)
tests/                          node --test
scripts/serve.py                캐시 없는 로컬 서버
```
