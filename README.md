# SpeechBoard: 면접 답변을 직접 돌아보는 도구

질문에 답한 뒤 자신의 영상·음성·측정값을 확인하고 메모를 남기는 브라우저 도구입니다. 제3자 평가, AI 답변 평가, 종합 점수, 등급, 자동 칭찬이나 행동 권고를 제공하지 않습니다. 무엇을 바꿀지는 사용자가 직접 판단합니다.

## 실행

```sh
npm start
```

터미널의 localhost 주소를 Chrome에서 엽니다. 정적 사이트 배포 시 HTTPS를 사용해야 장치 접근이 가능합니다. `file://` 대신 로컬 서버를 사용하세요.

```sh
npm test
```

Node 20 이상에서 계산·녹화 수명주기 테스트를 실행합니다. 런타임 패키지 설치는 필요하지 않습니다. 브라우저 검증 스크립트는 `scripts/browser-review-smoke.cjs`이며 별도로 설치된 Playwright 경로를 `PLAYWRIGHT_MODULE`로 지정해 실행합니다.

## 사용 흐름

1. **질문과 참고 범위 설정:** 질문, 답변 시간, 속도 및 정면 좌우·위아래 참고 범위를 정합니다. 프리셋은 편집 가능한 초기값이며 면접 성과 기준이 아닙니다.
2. **녹화 선택:** ‘답변을 녹화·녹음하여 직접 다시 보기’를 선택하면 카운트다운이 끝난 뒤 녹화를 시작합니다. 기본값은 녹화 안 함입니다. 카메라 없이 마이크만 있으면 녹음할 수 있습니다.
3. **준비 확인:** 2초간 정면과 주변 소음, 4초간 읽는 목소리를 측정합니다. 장치가 없는 경우 사용 가능한 측정만으로 진행할 수 있습니다.
4. **답변:** 기본적으로 실시간 지표를 숨깁니다. ‘측정값 보기’로 표시할 수 있습니다. 종료 버튼 또는 Esc로 끝냅니다. 설정 시간을 넘겨도 자동 종료하지 않습니다.
5. **직접 복기:** 영상 재생, 그래프 클릭, 키보드로 조작 가능한 시간 슬라이더로 특정 위치를 확인합니다. 위치별 메모와 전체 복기 메모를 남깁니다.
6. **재연습·비교:** 같은 질문으로 준비 확인을 다시 한 뒤 답변합니다. 같은 질문의 이전 실제 답변을 선택해 영상·측정값·메모를 함께 봅니다. 점수 차이나 자동 개선 판단은 표시하지 않습니다.

카운트다운 중 종료하거나 아주 짧게 답변해도 복기 메모를 남길 수 있습니다. 녹화 지원이나 파일 생성이 실패하면 그 이유를 표시하고 측정값·메모는 계속 사용할 수 있습니다.

## 보관과 삭제

- 영상·음성은 외부로 전송하지 않습니다. 외부 음성 인식 서비스도 실행하지 않습니다.
- 실제 답변은 **현재 탭의 메모리에 최근 5개**까지 보관합니다. 여섯 번째 답변을 만들면 가장 오래된 답변과 녹화가 해제됩니다.
- 새로고침하거나 탭을 닫으면 영상·메모·측정값이 사라집니다. 영구 저장소나 서버에는 저장하지 않습니다.
- 필요한 녹화 파일과 측정값·메모 JSON은 각각 다운로드할 수 있습니다. 다운로드한 파일은 사용자가 직접 관리합니다. 현재 버전은 JSON 재가져오기를 제공하지 않습니다.
- ‘이 녹화 삭제’는 현재 답변의 영상·음성만 삭제하고 메모는 유지합니다. ‘보관한 답변·메모 모두 삭제’는 탭 안의 답변 기록을 모두 지웁니다.
- 답변 종료 시 카메라·마이크를 끕니다. 재연습 시 준비 확인을 다시 진행합니다.
- 데모는 실제 답변 비교 기록에 저장하지 않습니다.

## 측정값 해석

- **정면 범위 안:** 얼굴이 검출된 표본 중 설정한 고개 범위와 눈 방향 기준 안에 있는 비율입니다. 실제 면접관과의 눈맞춤이나 면접 실력을 의미하지 않습니다. 얼굴 미검출은 별도 구간으로 표시합니다.
- **속도 추정:** 음량의 봉우리로 음절 수를 추정합니다. 실제 단어·음절을 인식하지 않아 오차가 있을 수 있습니다. 측정 가능한 표본의 평균과 측정 시간을 함께 표시합니다.
- **음량 변화:** 준비 확인 때 측정한 기준 대비 dB 차이입니다. 장치·거리·환경이 달라지면 답변 간 수치를 직접 비교하기 어렵습니다.
- **음높이 변화:** 발화로 추정된 구간에서 검출한 음높이의 반음 표준편차입니다. 자신감이나 전달력을 판정하지 않습니다.
- **시간·공백:** 실제 경과 시간과 10Hz 기록 표본에 해당하는 시간을 구분해 표시합니다. 백그라운드 탭이나 느린 기기에서는 표본이 누락될 수 있습니다. 공백을 가로질러 관찰 구간을 합치지 않습니다.

그래프와 참고 범위 구간 목록은 재생 위치를 찾는 데 사용합니다. 범위 밖이라는 이유만으로 문제가 있다고 판단하지 않습니다.

## 데모와 장치 점검

- `?demo=1`: 카메라·마이크 없이 가상 측정값으로 연습과 복기를 체험합니다. 녹화 파일은 생성하지 않습니다.
- `?debug=1`: 센서 원시값 표시.
- 설정 화면의 ‘시선 인식 테스트’: 안내된 방향과 감지값이 일치하는지 장치를 점검합니다. 이 화면의 일치율은 면접 수행 평가가 아닙니다.

## 구조

- `js/analysis/review.js`: 점수 없는 관찰 요약, 공백을 분리한 구간, 시각 기반 표본 조회
- `js/media-recorder.js`: 선택적 MediaRecorder 녹화 및 종료 처리
- `js/ui/setup.js`, `practice.js`, `report.js`: 질문 설정, 답변, 재생·메모·비교
- `js/sensors/`: 로컬 카메라·마이크 및 데모 센서
- `vendor/`: p5 및 MediaPipe 모델·WASM
- `tests/`: 단위·회귀 테스트

기존 `analysis/scoring.js`, `sensors/speech.js` 등 이전 평가·음성 인식 모듈은 회귀 참조용으로 남아 있지만 현재 화면 실행 경로에서 사용하지 않습니다. `docs/superpowers/`는 이전 발표 대시보드 설계 기록이며, 현재 동작은 이 README를 기준으로 합니다.
